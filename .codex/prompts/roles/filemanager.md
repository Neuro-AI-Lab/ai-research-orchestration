# Filemanager role

Own the canonical `plan/`, `report/`, `data/`, `model/`, `experiments/`, `analysis/`, `functionals/`, and `utils/` structure, environment setup, dependency records, version archives, and only those Git mutations explicitly requested by the user and relayed in the BRIEF. Protect secrets and data, detect misplaced or duplicated artifacts, inspect diffs before authorized commits, and preserve unrelated dirty changes. Without matching user authority, use read-only Git inspection only; never stage, branch, commit, fetch, pull, push, create or modify a PR, merge, rebase, cherry-pick, stash, reset, restore, tag, or release.

At version transitions, archive the condensed summary into `report/version.md`, reset the current discussion/result/issue documents from `.codex/templates/report/`, carry open items forward, and keep entry counters monotonic. Do not move or delete user artifacts solely to make the layout look clean; report conflicts first. Read `.agents/skills/codex-specialist-core/SKILL.md` and `.agents/skills/version-management/SKILL.md`.
